# Knowledge Base Document: KB-006
**Title:** Photography Portfolio Website Blueprint  
**Domain:** Website Generation · Design · Frontend · SEO · Content  

---

## 1. Purpose and Operational Mandate
The primary objective of `KB-006` is to provide coding and design agents with the exact product requirements, UX patterns, and component structures needed to build a world-class photography portfolio website (such as a portfolio for *John Doe*). It ensures the output is an immersive, professional-grade creative showcase rather than a generic corporate website.

---

## 2. Standard Page Structure & Information Architecture
A complete photography portfolio application must be structured across the following core routes:

* `GET /` — **Home Page:** High-impact immersive photography hero, curated featured gallery grid, brief artist statement, and primary CTA ("View Portfolio" / "Inquire").
* `GET /portfolio` (or `/gallery`) — **Comprehensive Gallery:** Full categorized image grid with interactive category filtering (e.g., Editorial, Landscape, Portrait, Street) and click-to-lightbox behavior.
* `GET /portfolio/[slug]` — **Individual Project / Shoot View:** Deep-dive view for a specific editorial shoot or project series, featuring an alternating or masonry photo layout, contextual description, and metadata (camera, location, year).
* `GET /about` — **Photographer Biography:** Personal background, artistic philosophy, client roster, awards, and equipment/studio details paired with a professional portrait.
* `GET /services` — **Services & Packages (Optional / Conditional):** Clear pricing tiers or engagement structures (e.g., Commercial Licensing, Portrait Sessions, Event Coverage).
* `GET /contact` — **Inquiry & Booking Form:** Validated contact form capturing client name, project type, budget range, preferred dates, and direct contact details.

---

## 3. Visual Design & Art Direction Rules
* **Image Dominance:** Photographs must dictate the visual experience. UI chrome, borders, and heavy backgrounds must recede entirely.
* **Color Palette:** Default to a high-end editorial canvas—deep obsidian dark mode (`#09090B`) or clean high-contrast gallery white (`#FAFAFA`) with subtle neutral borders (`border-zinc-800` / `border-zinc-200`).
* **Typography:** Pair high-contrast, elegant serif headings (`Playfair Display` or `Cormorant Garamond`) with neutral, highly legible sans-serif UI copy (`Inter` or `Plus Jakarta Sans`).
* **Whitespace & Pacing:** Use generous padding (`py-24` to `py-32`) to separate portfolio sections, giving visual assets room to breathe.

---

## 4. Image and Gallery Technical Requirements
* **Aspect Ratio Integrity:** Never stretch or distort images. All gallery items must enforce strict CSS aspect ratios (`aspect-[4/3]`, `aspect-square`, `aspect-[16/9]`) combined with `object-fit: cover`.
* **Lightbox Modal Engine:** Clicking any gallery thumbnail must trigger a high-resolution modal or fullscreen lightbox supporting keyboard navigation (Left/Right arrows, Esc to close) and caption overlays.
* **Responsive Image Pipeline:** Use responsive image source mapping or optimized CDN image URLs with explicit `width`, `height`, and `loading="lazy"` attributes to prevent layout shifts.
* **State Management:** Support smooth transition states for category filtering (e.g., fading items in/out when switching between "Landscape" and "Portrait").

---

## 5. Functional & Content Requirements
* **Frictionless Contact Form:** The inquiry form must validate all required fields (Name, Email, Message) using Zod schemas and display clear success/error states without breaking the page view.
* **Zero Fabrication Rule:** Do not invent fake high-profile awards, fictional Fortune 500 client lists, or unverified testimonials unless mock data is explicitly flagged as placeholder demonstration data.
* **Fully Linked Navigation:** All header and footer links must map correctly to active application routes. No dead links or placeholder `#` anchors.

---

## 6. Expected Deliverable
A fully working Next.js and Tailwind CSS application featuring responsive photography galleries, functional filtering, a modal lightbox, an "About" page, a validated contact inquiry workflow, and a verified production build.
